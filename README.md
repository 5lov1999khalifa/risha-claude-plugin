# ريشة لكتابة السيناريو في Claude

[English](README.en.md)

إضافة من ريشة استوديو تساعدك على صياغة سيناريو بالعربية أو الإنجليزية داخل Claude، وتحويله إلى مشروع `.trf` لفتحه في ريشة لكتابة السيناريو. اكتب من فكرتك، أو نسّق نصاً موجوداً، أو افحص ملف ريشة وعدّل حواره مع الحفاظ على بقية المشروع.

يصوغ Claude النص الإبداعي. أدوات ريشة تبني المشروع وتفحص بنيته وتعيد نسخة معدلة عند الطلب. فحص البنية لا يمنح اعتماداً فنياً أو مهنياً، وهذه الإضافة لا تعني أن Anthropic اعتمدتها في دليلها.

## التثبيت في Claude Code

تحتاج **Claude Code** وإصدار **Node.js 22 أو أحدث** يمكن للتطبيق تشغيله. الخادم المرفق يعمل محلياً؛ لا تحتاج مفتاح API أو حساب ريشة أو تنفيذ سكربت تثبيت npm لتشغيل نسخة التوزيع.

الإضافة متاحة في [مستودع ريشة العام على GitHub](https://github.com/5lov1999khalifa/risha-claude-plugin). نجح تثبيتها من المستودع واتصال أدواتها في Claude Code:

```text
claude plugin marketplace add 5lov1999khalifa/risha-claude-plugin
claude plugin install risha-screenwriting@risha-studio
```

افتح جلسة Claude Code جديدة واستخدم:

```text
/risha-screenwriting:screenplay
```

يمكن تجربة نسخة محلية دون تثبيتها دائماً: من جذر مجلد الإضافة شغّل `claude --plugin-dir .`. تنزيل المستودع عند التثبيت يتم عبر GitHub؛ معالجة أدوات السيناريو نفسها محلية ولا تتصل بخدمات توليد أو حسابات خارجية. [طريقة التثبيت الرسمية](https://code.claude.com/docs/en/discover-plugins).

## الاستخدام

- **مسودة جديدة:** «اكتب فيلماً قصيراً من مشهدين عن أخ وأخته يتصالحان بعد خلاف. الوصف بالفصحى والحوار إماراتي. احفظ لي ملف .trf جديداً.»
- **تنسيق نصك:** «حوّل النص الذي أرفقته إلى ملف ريشة جديد، وحافظ على الأحداث والحوار كما هي.»
- **فحص ملف:** «افحص ملف ريشة هذا دون تعديله، واشرح الأخطاء إن وجدت.»
- **تعديل محدد:** «افتح ملف ريشة الذي حددته، وعدّل الحوار في المشهد الثاني فقط. احفظ النتيجة كنسخة جديدة.»

حدد الملف أو أرفقه عندما يحتاج الطلب مشروعاً موجوداً. لا تبحث الإضافة تلقائياً في مجلداتك. لإنشاء ملف، اطلب حفظ نسخة جديدة وحدد مكان حفظها؛ ينفّذ Claude الحفظ بأدواته وصلاحياته، لأن أدوات ريشة لا تكتب على القرص.

## Claude Code وCowork والمحادثة

| المكان | ما تعمل به هذه الحزمة |
| --- | --- |
| Claude Code | المهارة والخادم المحلي المرفق، مع Node.js 22+ |
| Cowork في تطبيق الكمبيوتر | تحميل المهارة والخادم المحلي مدعوم في الجلسات التي تعمل على جهازك؛ يلزم اختبار هذه الحزمة هناك وتوافر Node في بيئة التشغيل |
| محادثة Claude على الويب أو الجوال | المهارة قد تُحمّل، لكن خادم stdio المحلي يُتجاهل؛ لا يتوفر فحص أو تصدير ريشة من هذه الحزمة وحدها |

في واجهة Claude يمكن إضافة مستودع Marketplace من **Customize → Plugins → Add → Add marketplace**، أو رفع ZIP من **Add → Upload plugin**. التثبيت من سطر أوامر Claude Code يبقى على الجهاز ولا يضيف الحزمة إلى حساب Claude تلقائياً. لم يُثبت اختبار هذه النسخة في Cowork أو محادثة Claude بعد. لدعم أدواتها داخل المحادثة يلزم خادم MCP عام عبر HTTPS وتوصيله، وهذا غير مضمن في الحزمة المحلية. [دعم المكونات حسب المنصة](https://claude.com/docs/plugins/platform-support).

## البيانات والحدود

يبدأ Claude برنامج Node المرفق ويتواصل معه عبر stdio. تستقبل الأدوات مادة السيناريو المحددة في كل طلب وتعيد نتيجتها؛ لا تقرأ ملفات مشاريعك، ولا تحفظها أو تسجل محتواها، ولا تجلب روابط أو تتصل بحساب ريشة. لا توجد hooks أو تتبع استخدام أو خدمات دفع في الإضافة. مادة المحادثة ونتائج الأدوات تظل خاضعة لإعدادات Claude وسياسات Anthropic؛ كلمة «محلي» تخص معالجة أدوات ريشة، لا نموذج Claude أو حفظ المحادثة.

تتعامل الأدوات مع **TRF v1 JSON كامل**. لا توفر قارئ PDF أو DOCX أو Final Draft، ولا تحسب صفحات الطباعة بدقة. حد المشروع 200 مشهد و10,000 عنصر و1 MiB من JSON. التعديل يغير نص عناصر موجودة ويعيد نسخة كاملة؛ إضافة العناصر وحذفها وإعادة ترتيبها وأعمال المراجعات الإنتاجية المقفلة تتم في برنامج الكتابة. لا تتصل الإضافة بمشاريع الحساب أو تزامنها أو تنشرها.

## الدليل الرسمي

التوزيع العام عبر GitHub متاح بوصفه Marketplace مستقل. الظهور في دليل Anthropic يحتاج تقديم الحزمة ومراجعتها ونشر النسخة المقبولة؛ لم تُقدّم هذه الحزمة إلى الدليل ولم تحصل على اعتماده. [خطوات التقديم](docs/DIRECTORY-SUBMISSION-AR.md).

نجح التثبيت من GitHub في إعدادات Claude Code معزولة، وظهر اتصال خادم الإضافة `Connected`. نجحت اختبارات الخادم المرفق 8/8 وفحص الحزمة والمهارة الرسمي. [نتائج التحقق وحدودها](docs/VERIFICATION-AR.md).
