# فحص إضافة ريشة لـClaude

3 أكتوبر 2026 — الإصدار 0.1.0. أعده Codex.

نجح فحص ملفات الإضافة والسوق والمهارة بواسطة Claude Code 2.1.234 مع `--strict`. نجحت تجربة إضافة السوق وتثبيت الإضافة وقراءة مكوناتها في إعدادات مؤقتة معزولة عن إعدادات المستخدم: مهارة `screenplay` واحدة وخادم MCP واحد، دون hooks أو agents أو LSP. تحقق اتصال Claude Code نفسه بالخادم في مساحة عمل فارغة، وظهر `Connected`. لا يعني ذلك اختبار Cowork أو المحادثة العادية.

نجحت اختبارات العميل الرسمي المتصل بالخادم المرفق 8/8. تشمل تعريف الأدوات الأربع، والعربي والإنجليزي، وملف TRF كامل، والحفاظ على المعرفات والحقول الإضافية والتنسيق، ورفض التعديلات غير الآمنة أو الإنتاجية المقفلة، وحدود المدخلات. شُغّلت الحزمة وحدها من مجلد اختبار بلا `node_modules`، وأثبت الفحص أن معالجة السيناريو لم تنشئ ملفات فيه.

الخادم المرفق قابل للقراءة وغير مصغر، وحجمه 1,390,206 بايت. يتضمن ثماني مكتبات runtime مثبتة الإصدارات مع تراخيصها في `vendor-notices/`. يجاوز حد 256 KiB الذي يستدعي مراجعة إضافية في دليل Anthropic؛ لم تحصل الإضافة على موافقة الدليل. وجود `package.json` في مصدر التطوير قد يسبب أيضاً تعليق مراجعة التثبيت الآلي؛ تشغيل المستخدم للحزمة لا يستدعي npm أو npx.

النسخة المحلية وحزمة ZIP جاهزتان. المستودع المقصود `5lov1999khalifa/risha-claude-plugin`، وقد أكد المالك هذا الحساب للنشر. فُتحت صفحة GitHub لتسجيل الدخول للحساب الصحيح؛ لم يُثبت إنشاء المستودع أو دفع الملفات بعد. لا يعتبر وجود الرابط في README دليلاً على النشر. تحدّث هذه الحالة بعد قراءة المستودع العام والتحقق من تثبيته من GitHub.

الأدوات المحلية تعمل وفق دعم Claude Code وCowork المحلي. محادثة Claude العادية لا تشغّل خادم stdio: تقدم المهارة مساعدة نصية عند غياب الأدوات، ولا تدّعي فحص مشروع أو تصدير ملف ريشة. اختبار Cowork الفعلي والخادم العام للمحادثة وتقديم الدليل ما زالت خطوات مستقلة.

لم تتغير تطبيقات ريشة الأصلية أو تكامل ChatGPT أو إعدادات Claude الأساسية أو ملفات العقل. رخصة MIT تخص كود هذه الإضافة؛ تراخيص المكتبات المرفقة محفوظة، ولا تتضمن الحزمة مصدر تطبيقات ريشة الأخرى.
